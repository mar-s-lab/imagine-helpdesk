# 🌐 Internacionalización

## Idiomas Soportados

| Código | Idioma | Bandera |
|--------|--------|---------|
| `es` | Español | 🇪🇸 |
| `en` | English | 🇺🇸 |
| `pt-BR` | Português (Brasil) | 🇧🇷 |

## Cómo Funciona

El sistema usa `LanguageContext` con un hook `useLanguage()` que expone:
- `language`: idioma actual
- `setLanguage(lang)`: cambiar idioma
- `t(key)`: función de traducción

Las traducciones están en `src/lib/i18n.ts` como un objeto plano por idioma.

## Cómo Agregar una Traducción

1. Abre `src/lib/i18n.ts`
2. Agrega la key en los 3 idiomas:

```typescript
export const translations = {
  es: {
    'mi.nueva.key': 'Texto en español',
  },
  en: {
    'mi.nueva.key': 'Text in English',
  },
  'pt-BR': {
    'mi.nueva.key': 'Texto em português',
  },
};
```

3. Usa en el componente:

```tsx
const { t } = useLanguage();
return <p>{t('mi.nueva.key')}</p>;
```
